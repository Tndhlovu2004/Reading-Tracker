# Reading Tracker

# About

This is a project designed to track the number of books a person has read over the course of a year. The user is able to enter any number of book titles/information, and the program records this data, allowing the user to exit and return to a list that was previously created. 

I mainly created this program becasue I really love reading, so I wanted to make something that corresponded with that interest. As my first personal project I wanted to make something that not only aligned with my interests, but was also something that I would genuinely use. 
I also wanted this to be a program in which I would be able to practice diffferent python concepts, allowing me to continue to work on my programming skills.

As an avid reader, I have always thought that applications that could track the number of books you have read over the course of a given period can be quite useful. However, I have found that the applications I have come across are not as simple and straightforward as I would prefer them to be. Therefore, I decided to come up with my own variation of this type of program that could be used in a more quick and easy manner. Thus, I was able to create a personal tool that I will use whislt also giving myself the opportunity to grow as a programmer.

# Features

- Allows the user to add books to their reading tracker.
- Records the user's name and current reading year.
- Allows the user to record the titles of their books, the date they finished reading and their rating.
- Allows the user to view the books they had previously added.
- Validates user input including the date and rating.
- Saves the user's book information.
- Allows the user's book information to be accessed in a future session.
- Provides messages to the user.
